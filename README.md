# Udhaya Prakash & Swetha — Wedding Invitation

Premium, responsive React wedding invitation built with:

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build for production

```bash
npm run build
npm run preview
```

## Included artwork

The supplied artwork is stored locally in `src/assets/`:

- `couple.jpeg`
- `groom.jpeg`
- `bride.jpeg`
- `god.jpeg`
- `wedding hall.jpeg`

No stock people or external photo assets are used.

## Notes

- The envelope + heart seal is the opening interaction.
- RSVP is intentionally omitted.
- The countdown targets 13 September 2026 at 4:00 AM IST.
- Google Maps buttons use the exact supplied links.
- Phone numbers use `tel:` links for mobile tap-to-call.
- Reduced-motion preferences are respected.
